# Game Shop

Um site para uma loja de jogos eletrônicos, oferecendo informações sobre a loja e canais de contato para os clientes.

## Descrição

Game Shop é um website simples e responsivo para uma loja de games física. O site apresenta informações sobre a loja, marcas parceiras, e disponibiliza um formulário de contato para os visitantes, além de links para as redes sociais e endereço físico.

## Funcionalidades

- **Página Única**: Design simples com navegação por âncoras
- **Seção Sobre**: Informações sobre a loja e marcas parceiras
- **Seção de Contato**: Formulário para mensagens e informações de contato
- **Redes Sociais**: Links para perfis da loja em plataformas sociais
- **Design Responsivo**: Adaptável a diferentes tamanhos de tela

## Tecnologias Utilizadas

- HTML5
- CSS3
- Fontes Google (Bungee e Roboto)

## Configuração & Instalação

1. Clone o repositório:
   ```
   git clone https://github.com/seuusuario/game-shop.git
   ```
2. Abra o arquivo `index.html` no seu navegador para visualizar o projeto.

## Seções do Site

- **Header**: Logo e menu de navegação
- **Sobre a Loja**: Descrição da loja e marcas parceiras (Nintendo, Xbox, PlayStation)
- **Contato**: Formulário de contato, links para redes sociais e endereço físico
- **Footer**: Informações de copyright
